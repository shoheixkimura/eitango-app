# ﾌﾞﾃﾞｨ

家族（最大4人）で使う、英文フラッシュカードの Web アプリです。
Anki の .apkg ファイルを取り込み、FSRS（目標の記憶率 90%）で復習を管理します。
表に英文と音声、答えを見ると和訳。「もう一度／むずかしい／できた／かんたん」の4段階で自分で評価します。
家族ランキング（今週の学習カード数・連続学習日数）で、続けたくなるようにしています。

- ビルドなしの HTML / CSS / JavaScript（ES モジュール）。GitHub Pages でそのまま公開できます。
- オフラインでも学習できます（PWA）。記録は端末に保存し、つながったときに家族の端末と同期します。
- 仕様は [spec.md](spec.md) にあります（Firebase は仕様とちがい、漢字アプリとは別のプロジェクトにしました）。

## 使い方

1. 最初の画面で、学習する人の名前とアイコンを登録します（4人まで）。
2. 「設定 → 家族の合言葉と同期」で合言葉を決めます（「自動で作る」も使えます）。家族の端末すべてに同じ合言葉を入れます。
   2台目からは、最初の画面の「家族の合言葉で記録をよびだす」から入れられます。
3. 「設定 → .apkg を取り込む」で単語帳を取り込みます。どのフィールドを英語（表）・和訳・音声・画像・品詞・例文・例文の訳・例文の音声にするかを、フィールド名と中身から自動で推定し、プレビューを見て変えられます。英文の単語帳でも、英単語の単語帳でも使えます。
   取り込んだ単語帳は、裏で Firestore にアップロードされ、同じ合言葉の端末すべてで使えます（ほかの端末ではホームの「ダウンロードする」）。
4. ホームの「学習をはじめる」で、今日の分（期限がきた復習＋新しいカード）を学習します。終わったら「新しいカードをあと10枚」で追加できます。

PC ではキーボードも使えます：スペース＝答えを見る（答えの画面では「できた」）、1〜4＝評価、R＝もう一度聞く、E＝例文を聞く。

### 対応する .apkg

- `collection.anki2` / `collection.anki21`（旧形式）
- `collection.anki21b`（新しい形式・zstd 圧縮）
- どれでもないときは「この形式は未対応です。Anki で『旧形式で書き出す』にチェックして書き出してください」と表示します。

同じ .apkg をもう一度取り込むと、同じ単語帳として上書きされ、学習記録はそのまま続きます（単語帳の ID は最上位のデッキ名から、カードの ID はノートの guid から決まります）。

### 日付を変えて試す

URL に `?date=2026-12-01` をつけると、その日として動きます（時刻は今の時刻のまま）。

### テスト

`tests.html` をブラウザでひらくと、FSRS の計算、日付と週の切りかわり、連続日数、2台の記録の合流、フィールドの推定、HTML を安全にする処理のテストが動きます。

ローカルで動かすとき（Service Worker と ES モジュールのため、ファイルを直接ひらくのではなくサーバーで）:

```bash
python3 -m http.server 8000
# http://localhost:8000/ と http://localhost:8000/tests.html
```

## Firebase の設定（無料の Spark プランのまま）

英文アプリ専用の Firebase プロジェクト `majianki` の Firestore だけを使います（漢字アプリとは別のプロジェクトです）。Blaze プランや Storage は要りません。

| 何を | どこに |
| --- | --- |
| 人の記録（名前・設定・日ごとの回答数） | `eitango_families/{合言葉のハッシュ}/profiles/{人のID}` |
| 各カードの FSRS の状態 | `eitango_families/{合言葉のハッシュ}/progress/{人のID}_{単語帳のID}` |
| 単語帳の一覧 | `eitango_families/{合言葉のハッシュ}/decks/{単語帳のID}` |
| 単語帳の本文と音声・画像 | `eitango_families/{合言葉のハッシュ}/blobs/{単語帳のID}_{版}_b0…`・`_m0…`（約900KBずつのかたまり） |

合言葉そのものはどこにも送りません（SHA-256 のハッシュだけを置き場所の名前に使います）。
市販教材の音声を扱うので、単語帳の中身は公開リポジトリや GitHub Pages には置かず、家族の合言葉の場所にだけ置きます。
接続先の値（`projectId`・`apiKey`）は `js/cloud-config.js` にあります。公開されてよい値で、データを守るのはルールと合言葉です。

### Firestore のルールを設定する

1. [Firebase コンソール](https://console.firebase.google.com/) で `majianki` をひらく
2. 左のメニュー「構築」→「Firestore Database」→ 上のタブ「ルール」
3. 書いてある文字を**全部消して**、[`firebase/firestore.rules`](firebase/firestore.rules) の中身を**全部はりつける**
4. 「公開」を押す

- 人の記録・カードの記録・単語帳の一覧は、読み取り・作成・更新ができ、削除はできません。
- 単語帳のかたまりは、1つずつの読み取りと新しく作ることだけができます（上書き・一覧・削除はできません）。1つ 950KB まで。

### 無料枠に収まるか

Spark プランの Firestore の無料枠は、保存 1GiB、読み取り 1日5万回、書き込み 1日2万回、転送 月10GiB です（2026年11月時点。最新は [Firebase の料金ページ](https://firebase.google.com/pricing) で確かめてください）。
Spark プランにはお支払い情報がないので、枠をこえてもお金はかからず、その日（その月）はクラウドが使えなくなるだけです（端末の中では学習を続けられます）。

DUO 3.0 のサンプル（560文・音声559個）の場合：

| | 量 | 無料枠に対して |
| --- | --- | --- |
| 保存 | 約33MB（かたまり39個） | 1GiB の約3%。同じくらいの単語帳なら30冊ほど置けます |
| 取り込み（1回だけ） | 書き込み約40回 | 1日2万回の 0.2% |
| ほかの端末でダウンロード（1台1回だけ） | 読み取り約40回・約33MB | 4台でも 約130MB で、月10GiB の約1.3% |
| ふだんの学習と同期 | 1回の同期で読み取り10回ほど | 4人が毎日使っても 1日数百回ほど |

同じ単語帳を取り込みなおすと、新しい版として全部アップロードしなおします（古い版のかたまりは残るので、気になるときは管理者が消してください）。

### 消したいとき

アプリからは、クラウドの記録や単語帳は消せません（「外す」は端末の一覧から外すだけです）。
完全に消すときは、管理者が Firebase コンソールの Firestore で `eitango_families` の中から消します。

## しくみのメモ

- 記録は端末の localStorage（人の記録 `eitango.v1`、カードの記録 `eitango.prog.{人のID}_{単語帳のID}`）、単語帳の本文と音声・画像は IndexedDB（`eitango`）に保存します。
- 2台で同時に使ったときは、カードごとに「復習回数が多いほう（同じなら最後に答えたのが新しいほう）」、日ごとの回答数は多いほうを採用します。
- 1回ごとの回答の履歴はクラウドに送りません。
- 連続学習日数は「その日の分（期限の復習＋新しいカード）を終えた日」が続いた日数です。今日まだでも、昨日まで続いていれば数は消えません。
- 週は月曜0時（端末の現地時間）に切りかわります。
- Service Worker のキャッシュ名は `eitango-v{バージョン}` です。新しい版を出すときは `js/config.js` の `VERSION` と `sw.js` の `CACHE` を上げます。
  同じ `github.io` のドメインにある漢字アプリが更新されると、このアプリのオフライン用キャッシュが消えることがありますが、次にネットにつながったときに自動で入れなおします（単語帳と記録は消えません）。
